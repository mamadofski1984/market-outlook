# چشم‌انداز بازارها

## اجرای نمونهٔ اولیه

با Node.js نسخهٔ ۲۰.۹ یا جدیدتر، در پوشهٔ پروژه اجرا کنید.

```powershell
npm ci
npm run dev
```

[داشبورد محلی](http://localhost:3000) را باز کنید. نصب اولیهٔ وابستگی‌ها به رجیستری npm یا کش محلی نیاز دارد. برنامه برای نمایش داده، نمودار و فونت به سرویس بیرونی درخواست نمی‌فرستد. اعداد و خبرهای نسخهٔ نمایشی ساختگی‌اند.

## ورود اکسل

در قالب نسخهٔ ۱.۰، داده‌ها را از ردیف ۶ وارد کنید. مقدار باید سلول عددی و تاریخ‌ها باید متن جلالی با قالب `YYYY/MM/DD` باشند. وضعیت باید یکی از `قطعی`، `تخمینی` یا `تأییدنشده` باشد.

```powershell
npm run import:xlsx -- "C:\path\to\workbook.xlsx"
```

فرمان، داده‌های معتبر را در فایل‌های بازار و نماد در `data/published/` ادغام می‌کند. برای بررسی یک فایل بدون تغییر داده‌های داشبورد، مسیر خروجی آزمایشی بدهید.

```powershell
npm run import:xlsx -- "C:\path\to\workbook.xlsx" "data-check"
```

خطاهای ورودی با شمارهٔ ردیف گزارش می‌شوند. دادهٔ قطعی موجود با برآورد جایگزین نمی‌شود. نمودار مقایسه‌ای پایهٔ مشترک ۱۰۰ دارد و محاسبات آن فقط از مشاهدات قطعی استفاده می‌کند.
